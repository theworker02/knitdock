# knitdock

Knit identifiers and dock tokens for idempotent workflows.

**Site:** https://theworker02.github.io/knitdock/

## Install / run

```bash
git clone https://github.com/theworker02/knitdock.git
cd knitdock
node src/cli.js
node --test
```
